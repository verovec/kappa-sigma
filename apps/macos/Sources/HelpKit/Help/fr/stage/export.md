Le jeu de livrables écrit depuis l'image du Studio : finale, sans étoiles et les mélanges d'étoiles, nommés par leur rôle.
Séparez les étoiles avec votre StarNet (une étape de l'historique) ; sans image sans étoiles, seule l'image finale est écrite.
Les fichiers vont dans exports/<empilement>/<date> du projet sauf autre dossier choisi ; les sources en lecture seule sont refusées. Exporter… : ⇧⌘E.
Terminé quand le projet enregistre au moins un export : chacun dit ce qui a été écrit, où et depuis quelle étape.
