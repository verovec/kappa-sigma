Le dossier de vos données astro : AstroStack le lit et n’y écrit jamais.
- **captures** : vos brutes, darks, flats et biais, par objet puis par nuit.
- **runs** : les empilements d’un autre outil, ouverts par Ouvrir un run….
- **library** : les maîtres de calibration tels quels ; **library/catalogues** tient les catalogues d’étoiles du plate solve et de SPCC (`just download-catalogues --spcc` les place sous le dossier choisi ici).
- **fixtures** : données de test. Des dossiers manquants conviennent : les Réglages disent lesquels existent.
