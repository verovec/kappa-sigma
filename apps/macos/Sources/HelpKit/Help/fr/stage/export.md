Le jeu de livrables écrit depuis l'image du Studio : finale, sans étoiles et mélanges d'étoiles, nommés par leur rôle.
Séparez les étoiles avec votre StarNet (une étape de l'historique) ; sinon, seule l'image finale est écrite.
Les fichiers vont dans le dossier d’export des Réglages et ses sous-dossiers, montré avant le clic ; Choisir… le change une fois. Refusés : sources en lecture seule, préfixes S3 lus par un projet ouvert. Exporter… : ⇧⌘E.
Terminé dès un export enregistré : chacun dit quoi, où, depuis quelle étape.
