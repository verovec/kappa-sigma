Le jeu de livrables écrit depuis l'image du Studio : finale, sans étoiles et les mélanges d'étoiles, nommés par leur rôle.
Séparez les étoiles avec votre StarNet (une étape de l'historique) ; sans image sans étoiles, seule l'image finale est écrite.
Les fichiers vont dans le dossier d’export des Réglages et ses sous-dossiers, montré avant le clic ; Choisir… le change pour un export. Les sources en lecture seule sont refusées. Exporter… : ⇧⌘E.
Terminé dès un export enregistré : chacun dit quoi, où et depuis quelle étape.
