Cliquez une étape de l'historique pour la modifier : son panneau s'ouvre avec les valeurs appliquées.
L'aperçu montre cette étape et toutes les suivantes recalculées ; il s'arrête avant un outil externe, lancé à la validation. Pendant un réglage, l'aperçu est calculé en résolution réduite (dit « aperçu réduit ») ; la pleine résolution revient dès que la valeur repose.
Appliquer la modification rejoue les étapes suivantes et garde l'ancienne chaîne dans Versions ; Annuler ne change rien. L'œil (ou ⌥-clic) compare.
